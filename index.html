06 Project missions

Selected builds

Project 01

Mini JIRA Task & Project Management Backend

Built a JIRA-inspired backend supporting project and task management, assignment, status tracking, validation, pagination, and exception handling. Designed User, Project, and Task services with API Gateway and asynchronous Kafka-based event processing.

Engineering decisions

  • Domain-split services (User, Project, Task) behind a single API Gateway entry point, so each service has a narrow responsibility.
  • Kafka carries events between services asynchronously, keeping cross-service work off the request path.
  • Spring Security with JWT for stateless authentication on the REST APIs.
  • Validation, pagination and centralised exception handling for predictable API responses, covered by JUnit tests.
  • Java
  • Spring Boot
  • Spring Data JPA
  • PostgreSQL
  • Spring Security
  • JWT
  • Kafka
  • REST APIs
  • JUnit

Project 02

Role-Based Access Control E-Commerce Application

Built secure REST APIs for Super Admin, Admin, Partner, and Customer workflows. Implemented JWT authentication, password hashing, product management, and an approval/rejection workflow for product listings.

Engineering decisions

  • Authentication and authorization kept separate: a JWT establishes identity, then role checks decide what each route allows.
  • Passwords are stored as bcrypt hashes, never in plain text.
  • Product listings move through explicit approval and rejection states rather than a single flag.
  • Node.js
  • Express.js
  • MongoDB
  • React.js
  • JWT
